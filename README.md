## :desktop_computer:Features

<div align=center>
  <img
    src='docs/image/app.png'
    alt='App Settings Page.'

### Main window (Shell page)

- 時計表示機能
- テーマ切り替え機能 (ライト/ダーク)
- ナビゲーション機能

### Settings page

- エクスプローラ起動機能 (設定ファイルのディレクトリ)
- 時計表示フォーマット変更機能
- 設定保存機能
